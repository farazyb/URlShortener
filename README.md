# URL Shortener

A URL shortening service built with Spring Boot, PostgreSQL, and Redis.

- Short codes are generated by base62-encoding a PostgreSQL sequence value, so they are unique without collision checks.
- Redirect lookups are cached in Redis, including short-lived negative entries for unknown codes.
- Requests are rate limited per client IP with [Bucket4j](https://bucket4j.com/), with bucket state stored in Redis so the limit holds across multiple instances.

## Tech stack

| Component      | Version / library                         |
|----------------|-------------------------------------------|
| Java           | 25 (Gradle toolchain)                     |
| Spring Boot    | 4.1 (Web, Data JPA, Cache, Actuator)      |
| Database       | PostgreSQL                                |
| Cache          | Redis (Jedis for caching, Lettuce for Bucket4j) |
| Rate limiting  | Bucket4j 8.18                             |
| Build          | Gradle, Cloud Native Buildpacks (`bootBuildImage`) |

## Getting started

### Prerequisites

- JDK 25 (or let the Gradle toolchain provision it)
- Docker, for PostgreSQL and Redis

### Run locally

Start PostgreSQL and Redis:

```bash
docker compose up -d
```

Run the application (uses the `dev` profile by default):

```bash
./gradlew bootRun
```

The service listens on `http://localhost:8080`. In the `dev` profile Hibernate creates the schema automatically (`ddl-auto: update`).

### Run tests

```bash
./gradlew test
```

## API

### Shorten a URL

```http
POST /api?url=https://example.com/some/long/path
```

The `url` must start with `http://` or `https://`.

Response `200 OK`:

```json
{
  "id": 100000,
  "originalUrl": "https://example.com/some/long/path",
  "shortUrl": "qNi",
  "createdAT": "2026-10-04T12:00:00Z"
}
```

Invalid input returns `400 Bad Request` with `{"error": "..."}`.

### Follow a short URL

```http
GET /api/{shortUrl}
```

Responds with `302 Found` and a `Location` header pointing at the original URL, or `404 Not Found` if the code is unknown. Codes are 3–8 alphanumeric characters.

### Rate limiting

Every request consumes one token from a bucket keyed by client IP (taken from `X-Forwarded-For` when present). Each bucket holds 5 tokens and refills 5 per minute. When it is empty the service responds with `429 Too Many Requests` and a `Retry-After` header. The limits are set in [`Bucket4jConfig`](src/main/java/com/example/urlshortener/config/Bucket4jConfig.java).

## Configuration

Settings are read from environment variables, with local defaults in [`application.yaml`](src/main/resources/application.yaml):

| Variable                 | Default                                   |
|--------------------------|-------------------------------------------|
| `SPRING_PROFILES_ACTIVE` | `dev`                                     |
| `SPRING_DATASOURCE_URL`  | `jdbc:postgresql://localhost:5432/mydb`   |
| `POSTGRES_USER`          | `myuser`                                  |
| `POSTGRES_PASSWORD`      | `mypass`                                  |
| `REDIS_HOST`             | `localhost`                               |
| `REDIS_PORT`             | `6379`                                    |
| `TRACING_SAMPLE_RATE`    | `0.1` (`prod` profile only)               |

### Profiles

- **`dev`**: auto schema updates, SQL and request logging, all Actuator endpoints exposed, 100% trace sampling.
- **`prod`**: schema validation only (`ddl-auto: validate`), INFO logging, limited Actuator endpoints.

Actuator endpoints are available under `/actuator` (`health`, `metrics`, `prometheus`, and more in `dev`).

## Container image

The image is built with Spring Boot Buildpacks and pushed to Docker Hub. It is tagged with the short git SHA, the project version, and `latest`:

```bash
REGISTRY_USER=<dockerhub-user> REGISTRY_PASS=<dockerhub-token> ./gradlew bootBuildImage
```

The credentials can also be passed as the Gradle properties `registryUser` and `registryPass`.

## Kubernetes

The manifests in [`application/`](application/) deploy the app (2 replicas behind a NodePort service), PostgreSQL, and Redis with a tuned config from a ConfigMap:

```bash
kubectl apply -f application/
```

These manifests are a work in progress. Secrets (database credentials) are not included in the repository, so you need to create your own, for example as a `Secret` or a [Sealed Secret](https://github.com/bitnami-labs/sealed-secrets).
